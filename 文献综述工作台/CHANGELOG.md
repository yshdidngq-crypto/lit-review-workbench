## V4.9

版式主题（可选）、图表多色盘、AI 味闸门。

- **新增 `assets/swiss.css`**：瑞士国际主义风格主题层，只覆盖 CSS 变量与形状

  关键设计：**先把 `<script>` 数据段整段剥掉再查**，只查模型自己写的文案。

  '闭环'、'显著提升' 立刻误伤 —— 学术文本里这些词完全正当，所以必须分层查。

## V4.8.3 — 2026-11-01

> 从同类 skill 偷了两条真正有用的东西：**DOI 要问注册中心**，**禁令要点名病灶**。
> 不新增校验项，30 项不变；新增的 `doi_check.py` 要联网，所以不进 validate。

### 新增
- `scripts/doi_check.py`：拿每个 DOI 去问 Crossref，查不到的再走 `doi.org` 解析服务
  （arXiv 的 `10.48550/*` 注册在 DataCite，Crossref 一律 404 —— 只查一家会把真论文误判成假 DOI）。
  四种结果分开报：已注册 / 题名对不上（多半套错了 DOI）/ 查无此 DOI / 未核验（网络失败，不算通过）。
  退出码 0 干净、1 有问题、2 被限流。实测 demo：27 条 DOI 全部已注册；塞一条假 DOI 立刻报 ✗。
- `SKILL.md` §4.1「反面清单」：把"不编造/不旁白"换成点名病灶的八条（给每篇写摘要、
  首先然后最后、效果写形容词、摘要当全文、本库没有当没人做过、方向配形容词、
  施工期信息上页面、自我评价）。
- `SKILL.md` §8 交付自检新增一条：`doi_check.py` 退出码 0；§9 目录补 `doi_check.py`。

### 为什么
`link.py` 只做字段配对，从不问"这个 DOI 存在吗"。而一个手抄错的 DOI 在页面上
安静地挂着、点开 404，整页看起来毫无异常 —— 这是最难被肉眼发现的错。

## V4.8.2 — 2026-11-01

> 补无障碍基线。这一版不动任何视觉尺寸与配色，所以「产出格式一致」的前提没变。

### 新增（骨架与锁死文件）
- `index.tpl.html`：正文前加跳转链接「跳到主内容」；`<nav>` 加 `aria-label="模块导航"`；
  搜索框、深色按钮、关闭按钮都给了 `aria-label`；`#view` 加 `tabindex="-1"` 便于焦点定位；
  详情抽屉改为 `role="dialog" aria-modal="true" aria-hidden`，遮罩层标 `aria-hidden="true"`。
- `base.css`：新增文件末尾的「无障碍」段 —— `:focus-visible` 焦点环（原来只有表单有 `:focus`，
  键盘 Tab 到按钮上看不出焦点在哪）、`prefers-reduced-motion` 减少动效、`.skip` 跳转链接样式。
- `app.core.js` / `app.bind.js`：导航当前项设 `aria-current="page"`；打开抽屉时记住来源焦点
  并把焦点移到关闭按钮，关闭时还原 —— 否则键盘用户点开一篇文献，焦点会被丢回页面顶部。

### 门禁
- 第 4 项「结构基线」顺带检查 4 条无障碍基线（跳转链接 / 焦点环 / 减少动效 / 导航标签），
  **不新增检查项**，总项数仍是 30。

## V4.8.1 — 2026-11-01

> 修两个「不报错、但会把内容弄错」的 bug。这类问题最值钱的地方在于：
> 产物看起来完全正常，只有回头读正文才会发现顺序或说法不对。

### 修复
- **`pdf2md.py` 双栏阅读顺序**：页面内排序原来只按 `y` 坐标，把栏号 `gi` 丢掉了。
  双栏论文里右栏 `y` 略小的行会插到左栏前面，整页变成按行交错——文本读起来仍然通顺，
  字数统计也正常，所以肉眼和门禁都发现不了。现在排序键改为 `(栏号, y)`，表格也补了栏号。
  实测：一页左右各 8 行、`y` 故意错开 15pt，修复前顺序是 `L0 R0 L1 R1 …`，
  修复后是 `L0…L7 R0…R7`。
- **`landscape.py` Q4 头条句**：原来写死「…；传统方法 %d 篇；…」，当篇数最多的一类
  本身就是「传统方法」时，会印出「传统方法 5 篇；传统方法 5 篇」。现在按实际第一名分两支：
  第一名是传统方法时说「传统方法 5 篇（xx.x%），是本批篇数最多的一类；其余派别合计 N 篇」，
  否则保持原句式。
- **生成的文件统一用 LF 换行**：脚本原来用文本模式写 `data/*.json` 与产物 HTML，
  Windows 上会被自动翻成 CRLF，于是同一份数据在不同系统上生成的文件字节不同——
  git 里表现为整个文件都被改动，`换人换机器产出一样` 也只覆盖内容、不覆盖字节。
  现在 12 处写入点显式写 `newline="\n"`。副作用：`demo/data/landscape.json` 重新生成后，
  顺带把 7 处早于生成器的旧措辞（「未报告数据集」→「本次未抽到数据集」等）对齐到当前版本。

## V4.8.0 — 2026-11-01

> 这一版动的是架构：**内容层从「必须重写」变成「可选覆盖」**。

### 新增
- **`assets/views.base.js`（锁死）**：十个内置页面 + 九个详情标签的通用实现，
  只读 `config.json` 与 `data/`，不含项目特有措辞。与 base.css / charts.js 同级锁定。
- `examples/data_only/`：零代码示例。只有 config + data，没有 `src/`，
  validate「23 项通过、1 项无数据未查」、smoke「全部通过」。

### 改动
- `build.py`：注入顺序加入 `views.base.js`（在 `src/views.js` 之前），
  收尾用 `Object.assign` 合并 —— 项目写过的覆盖同名项，没写的用通用版。
- `build.py`：`src/views.js` 与 `src/tabs.js` 改为**可选**。缺文件不再让构建失败；
  但「文件存在却没导出 window.VIEWS / window.TABS」仍然直接失败（那是写错了，不是选择不写）。
- `build.py`：构建日志新增「内容层来源」，说明这一版有几个页面是项目自己写的、几个用通用版。
- `validate.js`：视图层与详情页的失败提示同时给出「写 src/views.js」与「用通用骨架」两条路。

### 为什么
改之前，每个项目都要重新生成约 1,240 行 / 72 KB 的 `views.js`，其中九成是跨项目一模一样的
拼装代码（KPI 行、chartDonut/chartHBars、card/grid/table 调用）。以 `demo/src/views.js:126-223`
的 `window.VIEWS.dash` 为例，98 行里项目特有文字只有五六个字符串。代价是三项：
①每个项目的生成成本约 25k tokens 输出；②历史上所有版式 bug（年份 k/val、`L is not defined`、
六维网格挤爆）都长在这一层，因为它是唯一可自由改写的；③「产出完全一致」的承诺只覆盖 CSS 与图表，
不覆盖版式拼装。现在这一层锁死，一致性才真的说到做到，bug 也只需要修一次。

## V4.7.1 — 2026-11-01

> 这一版全部是「让门禁别撒谎 + 让文档跟得上代码」，没有新功能。

### 修复（门禁可信度）
- **「跳过」不再算进「全绿」**：`data/` 里缺少某份数据时，对应检查以前打 `ok` 混在通过里，
  现在单独打 `○` 并计数（`validate.js`），汇总行变成"（18 项检查通过、6 项无数据未查，1 项提醒）　共 24 项"。
  否则一个只有 `papers.json` 的项目也会被告知"24 项全绿，可以交付"。
- **`window.VIEWS` 缺渲染函数改判 ✗**（原来只是提醒）：`config.views` 里登记了却没有函数，页面就是死链。
- **方向树三级警告的 `undefinedundefined`**：`warns.push('…')` 推的是裸字符串，输出端读 `o.name`/`o.detail`，
  真触发时打不出话。改成 `warn(name, detail)`。
- **`undefined` / `NaN` 双查**：`validate.js` 新增正文扫描（前后 8 个字符内含中文即判泄漏，先剔注释），
  `smoke.js` 新增 `leakOf()`（剥 `<script>`/`<style>` 后按整词查，覆盖运行时才拼出来的泄漏），
  视图返回空串也算失败。此前两条门禁都放行过视图文字里的 `undefined`。
- **`test_click.js` 的三类假通过**：内层 `setTimeout` 回调异常不再逃出 try（以前不打印 ✗ → 判通过）；
  浏览器路径补 `EDGE_PATH` / Chrome / macOS，找不到时退出码 **2**（"没测"，不再是静默通过）；
  `file:///` 改用 `pathToFileURL`（中文路径不再加载失败）；加 `--user-data-dir`、超时与失败捕获。

### 修复（文档与代码对齐）
- 校验项数统一为 **30 项**（原文 13 处写 29）；「数据质量」是**最后一项**、「编号对照」是第 **28** 项。
- 详情标签统一为 **10 个**（6 本地 + 4 外部，`extWhy` 已在 V4.5 删除）；交互分支 **13** 个。
- 研究现状八问统一为 **Q1–Q8 连续编号**（`landscape.py` 早已是连续输出，`07` 文档还在教留空号）。
- 坑编号去重为 **坑 1–11**（原文坑 3、坑 4 各出现两次）。
- `lab` 入口规则统一为「V4.7 起默认不启用，需 `features.lab` 或 `--with-lab`，且先问用户」
  （原文有"强烈建议""默认不做""有文件就有入口"三套说法）。
- `views[].desc` / `project.subtitle` / `project.dataSource` 统一标注为**已废弃**（V4.6.1 骨架已删），
  原文一边说"不再渲染"、一边在自检清单里要求写。
- `pdf2md` 的说明更正：空壳与解析异常拦下（退出码 2），乱码与分栏只警告、md 照写（退出码 0）；
  删掉文档里并不存在的 `--gap-ratio` / `--stop-at-references`。
- 零散数字：DOM 模板锁死文件不再写"五个"、`landscape` 图例改为"图下不写"（与铁律 19 一致）、
  「三个视觉通道」改「四个」、demo 统一描述为 11 视图。

## V4.7.0 — 2026-11-01

### 新增
- **变更记录（本文件）**：随包发布，版本差异一眼可见。
- **工程实验室改为「用户自选」**：不再因为 `data/lab.json` 存在就自动加进侧栏。
  三种启用方式任选其一：命令行 `--with-lab`、`config.json` 里 `"features": {"lab": true}`、
  或在 `config.views` 里手写 `lab`。**都没写就不启用**，构建时会打印一行提示
  说明「有这个东西、怎么开」。
  理由：工程实验室是**辅助学习模块**（把方向拆成可执行模块、四级解释、失败案例），
  **仍在开发中**，生成内容**耗额度较多**。对只想要一份文献工作台的用户它是纯负担，
  替用户做决定是不合适的 —— 所以改成让用户自己选。

### 修复
- **饼图/散点气泡单色化**：主题没有 `color` 时，`topicColor()` 退化成 `var(--muted)`，
  环形图和气泡全部变成同一种灰，**分类维度整个消失**（事故：主题构成饼图全灰）。
  修复分两层：
  - 锁定层新增默认色板 `SERIES`（8 色），`chartDonut` / `chartScatter` /
    `topicColorOf()` 在缺少显式颜色时按序取色，不再全灰；
  - 新增门禁：**`config.topics` 每项必须带 `color`**，否则 `validate.js` 报 ✗。
- **热力矩阵表头被裁切**：`环节 × 主题` 矩阵的列头是分类全名（8–12 个汉字），
  配合 `white-space:nowrap` 会把表格撑出卡片右边界，读者只看到半截字。
  改为限宽换行（`max-width:86px`），完整名留在 `title` 里。
- **待审核数据永远是空的**：抽取脚本把解析问题只 `print` 到控制台，没写进
  `meta.json`，页面就一直显示「本次解析未记录异常」——读者看到的是
  「解析没发现问题」，而不是「没人查过」。现在抽取阶段的问题逐条落盘。
- **待审核项一次铺开几百条会撑爆页面**：改为**按字段分组**，每类默认显示 5 条，
  其余用原生 `<details>` 折叠（零 JS 依赖，不破坏离线自包含）。
- **数据集抽取被误杀**：用 `^(未|无|不详)` 前缀过滤空值，
  「**无人机**可见光航拍序列影像」因为「无人机」以「无」开头被整条丢弃 ——
  174 篇的数据集字段全空，「数据集可视化分析」报「识别出 0 个数据集」。
  改为**精确匹配**空值词表，并把「公共数据集」这类泛称排除（不指明具体数据集）。
- **开源代码字段全为「未提及」**：新增 `check_code.py` 走 OpenAlex 逐篇匹配，
  从摘要里找**出版方明写的** `github.com` 地址（只认硬证据，不凭记忆写）；
  匹配结果写进 `hasCode` / `codeUrl`。

### 变更
- 旁白短语库扩到 **33 类**：新增「全部由这批数据算出」（学习决策中心「三步阅读路径」
  卡片副题已删）。
- `validate.js` 新增 **1 项**检查（主题配色），总数 23 → 24。
