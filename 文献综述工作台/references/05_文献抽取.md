# 05 · 文献抽取（PDF → Markdown）

> 只在**用户给的是一堆 PDF** 时才需要本步骤。
> 如果用户已经给了精读 HTML / CSV / EndNote 导出，跳过，直接进 Step 1。

---

## 1. 先分清两种 PDF

| 类型 | 判断方法 | 处理方式 |
|---|---|---|
| 数字版（文字层完整） | 能选中、能复制正文文字 | `pdf2md.py` 直接抽，**不要做 OCR** |
| 扫描件（纯图） | 选中后是空白，或复制出来是乱码 | 必须先 OCR（tesseract / PaddleOCR），再进流程 |

先做一次判别，避免给数字版跑 OCR —— 又慢又错。

```bash
python scripts/pdf2md.py <PDF目录> -o <输出目录> --check-only
```

`--check-only` 会逐份报告"可抽取字符数 / 页数"，并列出被判定为扫描件的文件，不写任何文件。

---

## 2. 抽取

```bash
python scripts/pdf2md.py <PDF目录> -o <输出目录>
```

产出 `<输出目录>/<原文件名>.md`，以及一份 `manifest.json`（每份的页数、字符数、字/页、耗时、是否需 OCR、
以及"空壳 / 乱码 / 分栏错乱"三个标记）。

`manifest.json` 是**按文件名合并**的（V4.6）：分几次跑（比如先跑 2025 年再跑 2026 年），
前面的统计不会被后一次覆盖。旧版本是整体重写，分批跑只剩最后一批，这个问题已经修掉。

### 三道硬门禁（V4.6）

抽完之后脚本会自己查三件事，任意一条不通过就**不写这一份的 md**，并且整体退出码为 2：

| 门禁 | 判据 | 为什么必须拦 |
|---|---|---|
| 空壳 | 全文 0 字符 | 常是"只放了一张图"的占位 PDF。它会带着一个真标题混进库里，让所有占比失真 |
| 乱码 | 去掉空白后 `U+FFFD` 占比 > 6% | 字体编码异常的 PDF 能抽出几万字符，看着像成功，实际全是方块 |
| 分栏错乱 | 跨越中线（左侧起、右侧止）的行占全部行 > 30% | 双栏被交错拼成一句话，抽出来的"摘要"根本读不通 |

要写就加 `--write-anyway`；只是想让脚本别因为个别空壳文件整体失败，加 `--allow-empty`
（空壳文件仍不写 md，但退出码变 0）。默认行为是"宁可停，也不产出一份看着正常、其实不可用的 md"。

只依赖 PyMuPDF：

```bash
pip install pymupdf
```

> 为什么不用 markitdown / pymupdf4llm / marker：它们要么不处理双栏顺序、要么依赖模型下载（0.8–2 GB）、要么是 AGPL。
> 本脚本只做**版面重排**这一件事，200 行、零模型、可读可改。需要表格与公式的专业还原时再上 MinerU。

---

## 3. 它做了什么（这也是它的边界）

按顺序四件事：

1. **跨页重复行剔除** —— 同一段短文本在多页重复出现即判为页眉/页脚。判定前先做数字归一化，
   否则 `2 of 16` 与 `4 of 16` 因页码不同而被当成两行不同内容，页眉就剔不掉。
2. **分栏识别** —— 把页面横向切成 100 格，统计每格文字密度，在 30–70% 区间找密度低点作为栏间缝。
3. **阅读顺序重排** —— 先按 y 聚成"视觉行"，行内按 x 间距断开（间距 > 4% 页宽视为换栏），
   再按 (栏, y) 排序。这一步决定了双栏论文抽出来是通顺的还是乱序的。
4. **标题层级** —— 字号按**字符数加权取中位数**，不能取最大值（行内公式片段会把整行抬到 1.4 倍，
   被判成标题）；再加两条兜底：`SECTION_RE` 命中章节名、以及"同字号但加粗"（IEEE 体例）。

**它不做的事**：不识别表格结构、不还原公式为 LaTeX、不抽图片、不做语义分段。
抽出来的 md 是**给人读和给你自己解析**的中间产物，不是最终交付物。

---

## 4. 关键：不要停在 md

`md` 只是可读的中间态。**真正进流程的是 `data/papers.json`。**

```
PDF ──pdf2md.py──> .md ──你逐篇读并填表──> data/papers.json ──build.py──> HTML
```

读完 md 后按 `references/01_数据契约.md` 填 `papers.json`。判断标准很简单：

- 能填出 `overview` / `method` / `data` / `conclusion` 四段 → 这篇读过了
- 只填得出标题年份 → 没读，先别放进库

> 常见错误：把 300 份 md 直接喂进去让模型"抽取"，产出一堆摘要级条目。
> 那样做出来的工作台图表很好看，但结论全是虚的。宁可这一批只做 30 篇真读过的。

## 5. 已知失败模式与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 标题和正文粘连（`### Image Fusion Based on Differential 1. Introduction`） | 同一视觉行内有多个栏的文本 | 已由"行内按 x 间距断开"修复；仍出现说明栏间缝 < 4% 页宽，调 `--gap-ratio` |
| 公式被当成标题 | 行内数学符号拉高了字号 | 已由加权中位数 + `looks_like_formula()` 修复 |
| 章节标题缺失 | 同字号仅加粗（IEEE/MDPI） | 已由 bold 兜底修复 |
| 中文报告前面几万字全是目录 | 目录页每行都是"标题……页码" | 已由 `TOC_LINE` 正则过滤 |
| 整份文件抽取字符数 < 200/页 | 扫描件 | 走 OCR |
| 抽出来全是 `�` | PDF 字体没有 ToUnicode 映射 | V4.6 起会被"乱码"门禁拦住（占比 >6%）。改用 OCR，或换一份 PDF |
| 摘要读不通、两句之间突然接上半句 | 双栏交错拼接 | V4.6 起会被"分栏错乱"门禁拦住。5 篇 arXiv 双栏论文实测中招 |
| 0 字符 / 1 页 1 张图 | 占位或"需登录"的空壳 PDF | V4.6 起会被"空壳"门禁拦住。多半要回数据库重新下载全文 |
| 分批跑，前一批的统计没了 | 旧版 `manifest.json` 整体重写 | V4.6 起按文件合并，不会了 |
| 参考文献部分占了正文一半 | 参考文献没有独立标记 | 抽取后手工截断，或在 `--stop-at-references` 打开时自动截 |

## 6. 命令行参数

```
python scripts/pdf2md.py <输入目录或单个PDF> [-o 输出目录]
       --check-only        只做可抽取性判别、不写 md（判定要不要 OCR 就先用这个）
       --min-chars 200     每页最少字符数，低于此值判为扫描件
       --allow-empty       有空壳文件时不返回失败（空壳仍然不写 md）
       --write-anyway      强行写出门禁拦下的 md（空壳/乱码/分栏错乱），自己承担后果
```

`-o` 默认 `_extract`，产出 `<输出目录>/<原文件名>.md` 与 `manifest.json`
（逐份的页数、字符数、字/页、耗时、是否需 OCR）。
