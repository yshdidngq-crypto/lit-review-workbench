# 论文工作区预览（2026-11-03）

本分支为现有 174 篇单文件 HTML 增加 Zotero / Obsidian 风格的三栏论文工作区。
审核版 HTML 已随仓库发布：`showcase/文献工作台_三栏工作区预览_20261103.html`，线上入口在首页第二个按钮（GitHub Pages）。

## 可审核的流程

1. 在侧栏点“论文库整理”；左栏选择动态清单或文件夹，中栏搜索并选择论文。
2. 右栏查看题录、完整概述、关联方向与笔记；笔记输入自动保存到原有工作台状态。
3. 点“加入文献对比”会直接进入对比页。可搜索全部 174 篇，按年份、主题或同领域/跨领域筛选，横向和纵向查看所选论文。
4. 左栏可按主题与年份浏览，也可创建文件夹、添加自定义标签、移出分类或导出整理数据。“已阅读”显示已初读和已精读的论文。
5. 外部文献权重松手后切换到加权总分排序并更新列表。技术图谱与缺乏基准的环节缺口卡已从审核版界面移除。

审核版生成命令：`python preview/build_review.py <现有工作区预览.html> <输出.html>`。

## 数据边界

- 174 篇本库论文的输入 HTML 未提供 DOI 与独立原文摘要，因此显示“DOI 待核实”和概述全文。界面不会将概述称为已核实的原文摘要。
- 与 Zotero 的 API 同步、PDF 附件浏览和原文批注尚未接入。
- 笔记及整理状态留在当前浏览器；跨设备使用前需导出备份。

审核版生成后已对全部内嵌脚本执行 Node 语法检查。浏览器级交互检查待用户审核。
